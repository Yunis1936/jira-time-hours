# Jira: учёт времени в часах

Персональный userscript для Tampermonkey. Он меняет отображение трёх значений в блоке «Учёт времени» карточки Jira:

- «Оценка»;
- «Осталось»;
- «Затрачено».

Скрипт работает только на `jira.biz.zdravcity.rocks`, не отправляет запросов и не меняет данные задач. Он считает один рабочий день как 8 часов и неделю как 40 часов: `1d 4h 45m` отображается как `12,75 ч`. Дробные часы округляются до двух знаков после запятой: `5,33333` отображается как `5,33 ч`.

## Установка

1. Установить расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Нажать [Установить userscript](https://raw.githubusercontent.com/Yunis1936/jira-time-hours/refs/heads/main/jira-time-in-hours.user.js).
3. В окне Tampermonkey подтвердить установку и обновить открытую карточку Jira.

Рядом с каждым преобразованным значением появится `↺`: клик показывает исходный формат Jira, повторный клик возвращает часы.

## Повторная отрисовка Jira

Скрипт наблюдает за изменениями страницы и повторно находит «Учёт времени» после AJAX-подгрузки, смены вкладки, перемещения или повторной отрисовки блока. Он не создаёт дубли кнопок при повторной обработке.

## Проверка

```sh
node --test jira-time-in-hours.test.mjs
```
